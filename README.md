# Foush Print — الموقع + Google Sheets + GitHub Pages

## الفكرة
- **الشيت هو لوحة التحكم.** بتضيف/تعدل/تخفي المنتجات من Google Sheets، والموقع بيقراها.
- الموقع ملفات ثابتة بترفعها على GitHub Pages (مجاني).
- مفيش صفحة تحكم جوه الموقع. ده الأمان: محدش يقدر يعدل غير اللي عنده صلاحية على الشيت.

## 1) جهّز الشيت
1. افتح Google Sheets وأنشئ ملف جديد، وسمّي التابات: `Products` و`Portfolio` و`Settings`.
2. في كل تاب: File ← Import ← Upload، واختار الملف المقابل من فولدر `sheet-templates`، واختار "Replace current sheet".
3. امسح صفوف الأمثلة وحط منتجاتك.

### أعمدة Products
| العمود | الاستخدام |
|---|---|
| id | اختياري، حروف إنجليزي وأرقام و - (مثال: sticker-01) |
| name | اسم المنتج (مطلوب) |
| category | اسم التصنيف. لو كتبت تصنيف جديد بيظهر تلقائي في الموقع بصفحة وفلتر |
| description | وصف |
| price | لو فيه سعر بيظهر. لو فاضي بيظهر "اطلب عرض سعر" |
| sizes / materials | قيم مفصولة بفاصلة |
| images | أكتر من صورة بفاصل `|` (مثال: a.jpg|b.jpg). الأولى هي الرئيسية |
| featured | نعم = يظهر في الرئيسية |
| visible | لا = يتخفي من غير حذف |
| order | رقم الترتيب، الأصغر أولًا |

## 2) الصور (اختار طريقة)
- **الأسهل والأسرع:** ارفع الصور في فولدر `images` على GitHub واكتب اسم الملف فقط في الشيت.
- **أو Google Drive:** خلّي الصورة "Anyone with the link" وألصق رابطها في الشيت (الموقع بيحوله لوحده).

## 3) انشر الشيت (للقراءة فقط)
1. File ← Share ← **Publish to web**.
2. اختار تاب واحد (مثلًا Products) وصيغة **CSV** ← Publish، وانسخ الرابط.
3. كرر مع Portfolio وSettings.
4. الصق الروابط الثلاثة في `config.js`.
> المنشور هو الجداول دي بس. تجنب تحط أي بيانات عملاء أو أرقام تليفونات فيها، لأن رابط CSV عام. لو عايز تابات خاصة (طلبات مثلًا) سيبها من غير نشر.
> أي تعديل في الشيت بيظهر على الموقع بعد حوالي 5 دقائق.

## 4) ارفع على GitHub Pages
1. أنشئ حساب GitHub ثم New repository (مثلًا `foush-print`) بوضع Public.
2. Add file ← Upload files، وارفع `index.html` و`config.js` وفولدر `images` ← Commit.
3. Settings ← Pages ← Source: **Deploy from a branch** ← `main` / root ← Save.
4. بعد دقيقتين الرابط بيظهر: `https://اسمك.github.io/foush-print/`.

## الدخول للتحكم بعد كده
- افتح الشيت من drive.google.com أو sheets.google.com بحسابك وخزّنه في المفضلة.
- لتعديل صور أو كود الموقع: ادخل على github.com ← الريبو.

## الأمان
- فعّل التحقق بخطوتين (2-Step Verification) على حساب Google وحساب GitHub.
- شارك الشيت (Share) بالإيميلات الموثوقة فقط، وبصلاحية Editor لمن يحتاج.
- ما تضعش كلمات مرور أو بيانات عملاء في التابات المنشورة.

## حدود لازم تعرفها
- الطلبات بتتبعت على واتساب. الموقع مش بيخزنها ولا بيرسلها لقاعدة بيانات.
- الموقع بيستخدم `#` في الروابط، فتهيئة SEO لكل صفحة لوحدها محدودة. صفحة الرئيسية فيها عنوان ووصف وبيانات منظمة.
- مفيش إدارة طلبات أو عملاء أو إحصائيات هنا. ممكن تعملها في تاب خاص في الشيت.
- جرّبت الكود على محاكاة بسيطة بدون متصفح. جرّب الموقع بعد النشر وتأكد إن المنتجات والصور بتظهر.

## تحديثات (الإصدار الأخير)

### أعمدة Products الجديدة
`id, name, category, subcategory, description, price, sizes, materials, quantities, images, image_urls, featured, visible, order`

- **category**: الفئة الرئيسية (مثال: الطباعة التجارية).
- **subcategory**: التصنيف الفرعي جوه الفئة (مثال: كروت بيزنس، استيكر). بيتعرف بالاسم حتى لو اختلف الحرف شوية (ة/ه، أ/ا، ال).
  لو كتبت تصنيف فرعي جديد بيظهر تلقائي كفلتر.
- **price**: رقم فقط (مثال: 150). الموقع بيحسب إجمالي الحساب = السعر × الكمية. لو فاضي أو نص بيظهر "اطلب عرض سعر".
- **quantities**: كميات ملزمة مثل `50 - 100 - 200 - 300`. لو فاضي العميل يكتب أي كمية من 1.
- **images**: مسار AppSheet أو أسماء ملفات. **image_urls**: بيتملا تلقائي من سكربت Drive (تحت).

### صور AppSheet من Drive
المسار في AppSheet (زي `Products_Images/abc.jpg`) مش رابط، فالمتصفح ما يقدرش يفتحه. الحل:
1. في الشيت: Extensions ← Apps Script، الصق محتوى `apps-script/images.gs`.
2. شغّل `installTrigger` مرة واحدة ووافق على الصلاحيات.
3. السكربت كل 5 دقائق بيدور على الملف في Drive، ويخليه "أي حد معاه الرابط يعرض"، ويكتب الرابط في `image_urls`، والموقع بيعرض الصور منه.
> ملاحظة أمان: الملفات المرتبطة بالمنتجات بتبقى عامة. ما تستخدمش السكربت على جداول فيها صور خاصة (فواتير مثلًا).
> الملفات لازم تكون في Drive بتاعك (نفس حساب الشيت).
